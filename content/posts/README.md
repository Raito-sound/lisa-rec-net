# 新規ブログ記事

今後の記事はこのフォルダに Markdown で保存する。Wixから移行した記事のJSONは `content/blog/` に保管し、直接編集しない。

## 基本の流れ

1. `_template.md` を複製し、`YYYY-MM-DD-slug.md` という名前にする
2. タイトル、公開日、概要、本文を記入する
3. 記事内容に合わせて、AIが管理候補からタグを1〜3個選ぶ
4. 画像がある場合は `assets/blog/<slug>/` に配置する
5. `python3 _tools/build_blog.py` を実行する
6. ブラウザで確認してから公開する

本文では見出し、箇条書き、引用、リンク、画像、YouTubeを利用できる。画像のパスはファイル名だけを書く。

```md
![写真の説明](photo.jpg "任意のキャプション")

{{youtube:VIDEO_ID}}
```

`cover` はブログ一覧とOGPで使う代表画像。本文にも表示したい場合は本文中にも画像記法を書く。

`tags` は執筆者が決める必要はない。原稿全体を読んだAIが `content/blog-tags.json` の管理候補から1〜3個を選び、カンマ区切りで設定する。候補外の表記や4個以上のタグは生成時にエラーとなるため、似たタグが無秩序に増えない。タグは記事の構造化データにも入り、検索AIが主題を判断しやすくなる。
